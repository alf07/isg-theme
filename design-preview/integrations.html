Демонстрация интеграций

Интеграции — без внешних вызовов

Набор локальных сценариев для демонстрации архитектуры. Каждый сценарий возвращает тестовый результат с reference ID. Никакие платежи, сообщения в Telegram или запросы к AI не выполняются.

Граница безопасности: все кнопки ниже — локальные заглушки. Они не подключены к боевым API и не требуют секретных ключей.

Сценарий 01

Платёжный провайдер

Проверка последовательности: создать платёж → получить статус → отдать результат заказу. Реальная оплата отключена.

Сценарий 02

Цифровая выдача

Имитация запуска обработчика после подтверждения заказа. Фактический цифровой товар не выдаётся.

Сценарий 03

AI-помощник

Демонстрация границы между интерфейсом чата и адаптером AI-провайдера. Ответ генерируется локально как результат заглушки.

Сценарий 04

Передача оператору в Telegram

Имитируется формирование handoff-события. Сообщение в Telegram не отправляется.

Предлагаемый контракт интеграции

{
  "ok": true,
  "demo": true,
  "provider": "payment | digital_delivery | ai_assistant | telegram",
  "reference": "DEMO-XXXXXX",
  "message": "Демонстрационный сценарий выполнен локально"
}

В плагине `isg-site` есть аналогичная PHP-функция, которая возвращает структурированный ответ. Реальный провайдер можно подключить отдельно, сохранив контракт и не размещая секреты в шаблонах.
